# Soniya Reddy Bheemireddy - Portfolio

A modern, aesthetic single-page portfolio website built with HTML, CSS, and JavaScript.

## Features
- **Responsive Design**: Fully functional on mobile and desktop.
- **Glassmorphism UI**: Modern frosted glass effect for cards and sections.
- **Floating Animations**: Dynamic hero section with floating elements and blobs.
- **Interactive Timeline**: Clickable experience entries (e.g., ISTE section shows event photos).
- **Smooth Scrolling**: Easy navigation with a fixed navbar.
- **Detailed Sections**: Home, About, Education, Skills, Projects, Experience, and Contact.

## Technologies Used
- HTML5
- CSS3 (Vanilla)
- JavaScript (ES6+)
- Font Awesome
- Google Fonts (Outfit)

- **ShopSmart**: Smart Retail Management System.
